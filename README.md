# booklist-spa - Annabel Canela - Modulo 6

SPA Vue 3 + Vite para gestión de libros.

Funcionalidades:
- Inicio de contador Pinia
- Lista de Libros con registro (El Aleph, Don Quijote) en localStorage
- Detalle de Libro con Volver al Listado

Tecnologias: Vue 3, Vue Router, Pinia, Localstorage

Ejecución: npm install / npm run dev
Playground: https://play.vuejs.org
